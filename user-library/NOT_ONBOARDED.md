# Not onboarded yet

This folder is where **your** personal job-application files live. It's empty
because you haven't been onboarded yet.

The presence of this `NOT_ONBOARDED.md` file is how the skill knows this is your
**first run**. The first time you use it, the skill briefly explains what it does
and what you'll need to provide, then kicks off **onboarding** — a ~5 or ~20 minute
setup that builds:

- `profile.json` — your contact info, links, work authorization, and the standard
  answers application forms ask for
- `base_resume.md` — your master resume
- `fact-pack.md` — your real roles, metrics, stories, hooks, and honest gaps
- `voice.md` — how you write, so cover letters sound like you
- `format.json` — your resume's fonts and colors
- `scanner_config.json` + `seen_postings.json` — optional, only if you set up job
  scanning

To get started, just say **"onboard me"** (or paste a job description and the skill
will offer to set you up first).

Once onboarding finishes, this file is deleted and your real library files take its
place. Everything in this folder stays on your own machine — see the privacy note
in the README.
